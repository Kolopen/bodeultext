WSL2 + Kaldi 설치와 제거 (Windows, RTX 5070)
================================================

원칙: 리눅스 전체를 E: 안의 파일 하나에 넣어 둔다.
      지울 때는 그것만 지우면 노트북에 아무것도 남지 않는다.
설치 위치: E: (SAMSUNG, 남은 공간 211GB)

공간 계획 (1차: 의사_1 + 환자_1, 약 110시간)
  Ubuntu + CUDA + Kaldi                 약 20GB
  압축 푼 음성 (Training + Validation)  약 56GB
  학습 중간 파일                        약 40~60GB
  zip (하나씩 풀고 바로 삭제)           한 번에 최대 약 20GB
  합계                                  약 140~160GB  -> 211GB 안에 들어간다
  * AI-Hub 전체(약 290GB)는 E: 에 안 들어간다. 늘릴 때는 공간을 따로 마련한다.


############################################################
#  A. 설치
############################################################

[1] Windows 쪽 준비
------------------------------------------------------------
- NVIDIA 드라이버를 최신으로 업데이트한다 (평소 쓰는 NVIDIA 앱에서).
  Windows 에는 CUDA 를 따로 깔지 않는다.
- E: 의 파일 시스템이 NTFS 인지 확인한다.
  파일 탐색기 -> E: 오른쪽 클릭 -> 속성 -> "파일 시스템" 이 NTFS 면 된다.
  exFAT 이면 안 된다 (이때는 진행하지 말고 먼저 물어본다).
  포맷할 필요는 없다. E: 의 기존 파일은 건드리지 않고 E:\wsl 폴더만 새로 생긴다.


[2] Ubuntu 설치  -  관리자 PowerShell
------------------------------------------------------------
wsl --install -d Ubuntu-24.04

-> 재부팅. Ubuntu 창이 뜨면 사용자 이름과 암호를 만든다.


[3] Ubuntu 를 E: 로 옮기기  -  관리자 PowerShell
------------------------------------------------------------
wsl --shutdown
mkdir E:\wsl
wsl --export Ubuntu-24.04 E:\wsl\ubuntu.tar
wsl --unregister Ubuntu-24.04
wsl --import Ubuntu-24.04 E:\wsl\ubuntu E:\wsl\ubuntu.tar
del E:\wsl\ubuntu.tar

이제 리눅스 전체가 E:\wsl\ubuntu\ext4.vhdx 파일 하나에 들어 있다.

안에서 파일을 지워도 이 파일은 줄지 않는다(지운 자리는 Ubuntu 가 다시 쓴다).
그래서 zip 은 Ubuntu 밖(E:\aihub-zip)에 받아 바로 지운다.
'wsl --manage ... --set-sparse true' 는 Microsoft 가 데이터 손상 위험으로 막아 두었다.
--allow-unsafe 로 강제로 켜지 않는다.


[4] 로그인 사용자 되돌리기  -  Ubuntu 터미널
------------------------------------------------------------
wsl -d Ubuntu-24.04 로 열었을 때 이미 내 사용자 이름(예: loodad@...)이면 건너뛴다.
root@... 로 나올 때만 아래를 한다.

sudo tee /etc/wsl.conf <<'EOF'
[user]
default=<처음 만든 사용자 이름>
EOF


[5] 메모리 한도  -  메모장
------------------------------------------------------------
C:\Users\<내 이름>\.wslconfig 파일을 만들고 아래 두 줄을 넣는다.
(RAM 16GB 면 12GB, 32GB 면 24GB 정도)

[wsl2]
memory=12GB

-> PowerShell 에서 wsl --shutdown 후 Ubuntu 를 다시 열면 [4], [5] 가 적용된다.


[6] 필요한 프로그램  -  Ubuntu 터미널
------------------------------------------------------------
sudo apt update
sudo apt install -y build-essential git automake autoconf libtool sox gfortran python3 python3-pip zlib1g-dev wget unzip unar subversion libopenblas-dev locales python-is-python3
sudo locale-gen en_US.UTF-8
pip3 install --break-system-packages morfessor

nvidia-smi
-> RTX 5070 이 보이면 GPU 연결 성공


[7] CUDA 12.8  -  Ubuntu 터미널
------------------------------------------------------------
wget https://developer.download.nvidia.com/compute/cuda/repos/wsl-ubuntu/x86_64/cuda-keyring_1.1-1_all.deb
sudo dpkg -i cuda-keyring_1.1-1_all.deb
sudo apt update
sudo apt install -y cuda-toolkit-12-8

/usr/local/cuda/bin/nvcc --version
-> 12.8 이 나오면 성공


[8] Kaldi 빌드 (2~3시간)  -  Ubuntu 터미널
------------------------------------------------------------
메모리가 12GB 라 동시 작업 수를 4 로 둔다 (-j 4). 8 로 하면 메모리가 모자라 멈출 수 있다.

cd ~
git clone -b claude/eloquent-cray-29ssw9 https://github.com/Kolopen/bodeultext.git
git clone https://github.com/Kolopen/-AI.git

cd ~/bodeultext/tools
extras/check_dependencies.sh
-> "Intel MKL does not seem to be installed", "python2.7 is not installed" 는 무시한다.
   그 밖에 설치하라는 것이 있으면 sudo apt install 로 설치한다.

make -j 4

OPENBLAS_TARGET=HASWELL extras/install_openblas.sh
-> 행렬 계산 라이브러리. OPENBLAS_TARGET=HASWELL 이 없으면 최신 CPU 에서
   "Detecting CPU failed" 로 멈춘다. 마지막에 "OpenBLAS is installed successfully." 가 나와야 한다.

~/bodeultext/egs/aihub_medical/s5/local/configure_kaldi.sh
-> 긴 configure 명령을 대신 실행한다 (RTX 50 시리즈, CUDA, OpenBLAS 설정 포함).
   마지막 쪽에 "Kaldi has been successfully configured." 가 나와야 한다.

cd ~/bodeultext/src
make depend -j 4
make -j 4
-> 가장 오래 걸린다. 끝에 "Done" 이 나오면 성공.

확인:
cd ../egs/yesno/s5
./run.sh
-> 마지막에 %WER 0.00 이 나오면 설치 끝


[9] 데이터 받기  -  Ubuntu 터미널
------------------------------------------------------------
AI-Hub 에서 받은 파일은 겹겹이 싸여 있다.
  받은 파일(tar, 브라우저가 '환자1' 처럼 이름을 바꾸기도 함)
   └─ ...원천데이터/환자_1.zip.part0, .part1073741824, ...  (진짜 zip 의 1GB 조각들)
local/unpack_aihub.py 가 이걸 한 번에 처리한다. 반디집, 조각 합치기 필요 없다.

받은 파일은 이름 그대로 E:\aihub-zip 에 모은다 ('미확인 323442.crdownload' 같은 이름도 괜찮다).
cd ~/bodeultext/egs/aihub_medical/s5

1) 무엇인지 확인 (안쪽 경로로 Training/Validation, 음성/라벨 을 알아낸다):
python3 local/unpack_aihub.py --list /mnt/e/aihub-zip/*

2) 한 번에 처리:
python3 local/unpack_aihub.py /mnt/e/aihub-zip/* --auto /mnt/e/aihub
-> Training 음성   -> E:\aihub\train\audio  (wav 로 꺼냄)
   Validation 음성 -> E:\aihub\valid\audio
   Training 라벨   -> E:\aihub\train\labels\train_labels.zip  (풀지 않고 zip 하나로)
   Validation 라벨 -> E:\aihub\valid\labels\valid_labels.zip
-> 끝에 "깨짐 0" 이면 E:\aihub-zip 의 받은 파일을 지운다.
-> 중간에 멈췄으면 같은 명령을 다시 하면 이어서 한다 (끝난 파일은 건너뜀).
-> "끝까지 다운로드되지 않았습니다" 가 나오면 그 파일만 다시 받는다.

df -h /mnt/e
-> 남은 공간은 이걸로 본다 (df -h ~ 는 가상 크기라 실제보다 크게 나온다).

라벨 점검, 학습은 같은 폴더의 README.md 5~6절.


[10] 컴퓨터를 끌 때 / 다시 켤 때
------------------------------------------------------------
끌 때:
  1. 돌고 있는 명령이 있으면 끝날 때까지 기다리거나 멈춘다.
     - 창에 바로 띄운 명령(unpack_aihub.py 등): Ctrl+C
     - nohup ... & 로 띄운 학습(run.sh, run_tdnn.sh): local/stop_training.sh
     (다시 실행하면 이어서 한다. 학습을 이어 하는 법은 다음단계.txt 의 [3])
  2. Ubuntu 창에서:  exit
  3. PowerShell 에서: wsl --shutdown
  4. Windows 를 평소처럼 끈다.
  * E: 가 외장 SSD 면, 3번을 한 뒤에 뽑는다. Ubuntu 가 E: 안에 있다.

다시 켤 때:
  1. (외장 SSD 면) E: 를 먼저 꽂는다.
  2. 시작 메뉴 -> 터미널 -> 위쪽 v 버튼 -> Ubuntu-24.04
     (또는 PowerShell 에서 wsl -d Ubuntu-24.04)
  3. Ubuntu 창에서:
       cd ~/bodeultext && git pull
       cd ~/bodeultext/egs/aihub_medical/s5
  4. 하던 단계부터 이어서 한다.
     - 데이터 꺼내기: 같은 unpack_aihub.py 명령을 다시 (끝난 파일은 건너뜀)
     - 학습: ./run.sh --stage N ...  (N 은 멈춘 단계, run.sh 맨 위 참고)
     - 신경망: 다음단계.txt 의 [3] (단계 번호 표가 있다)

[1] 남길 것 먼저 빼기  -  Ubuntu 터미널
------------------------------------------------------------
학습한 모델만 E: 의 Windows 쪽 폴더로 복사한다 (수백 MB).

mkdir -p /mnt/e/kaldi-model
cd ~/bodeultext/egs/aihub_medical/s5
cp -rL exp/chain/tdnn1a_online exp/chain/tree/graph exp/chain/tree/graph_big /mnt/e/kaldi-model/
cp exp/chain/tdnn1a/decode_test/scoring_kaldi/best_cer /mnt/e/kaldi-model/graph/
(graph_big 은 언어모델 넓히기를 했을 때만 있다. 없으면 빼고 복사한다.)


[2] 이름 확인  -  관리자 PowerShell
------------------------------------------------------------
wsl -l -v

-> 목록의 이름이 Ubuntu-24.04 가 아니면 아래 명령에서 그 이름으로 바꾼다.


[3] Ubuntu 삭제  -  관리자 PowerShell
------------------------------------------------------------
!! Kaldi, CUDA, AI-Hub 데이터, 학습 결과가 전부 지워진다. 되돌릴 수 없다. !!

wsl --shutdown
wsl --unregister Ubuntu-24.04
Remove-Item -Recurse -Force E:\wsl
Remove-Item -Recurse -Force E:\aihub-zip
Remove-Item $env:USERPROFILE\.wslconfig


[4] 시작 메뉴의 Ubuntu 앱 제거
------------------------------------------------------------
설정 -> 앱 -> 설치된 앱 -> "Ubuntu 24.04 LTS" -> 제거
(목록에 없으면 건너뛴다)


[5] WSL 기능까지 끄기 (선택: 다시 안 쓸 때만)  -  관리자 PowerShell
------------------------------------------------------------
wsl --uninstall
dism /online /disable-feature /featurename:Microsoft-Windows-Subsystem-Linux /norestart
dism /online /disable-feature /featurename:VirtualMachinePlatform /norestart

-> 재부팅하면 설치 전 상태.

NVIDIA 드라이버는 원래 쓰던 것이라 그대로 둔다.
Windows 쪽에는 CUDA 를 깔지 않았으므로 지울 것이 없다.
