WSL2 + Kaldi 설치와 제거 (Windows, RTX 5070)
================================================

원칙: 리눅스 전체를 E: 안의 파일 하나에 넣어 둔다.
      지울 때는 그것만 지우면 노트북에 아무것도 남지 않는다.
설치 위치: E: (SAMSUNG, 남은 공간 211GB)

공간 계획 (1차: 의사_1 + 환자_1, 약 110시간)
  Ubuntu + CUDA + Kaldi                 약 20GB
  압축 푼 음성 (Training + Validation)  약 56GB
  학습 중간 파일                        약 40~60GB
  zip (하나씩 풀고 바로 삭제)           한 번에 최대 약 20GB
  합계                                  약 140~160GB  -> 211GB 안에 들어간다
  * AI-Hub 전체(약 290GB)는 E: 에 안 들어간다. 늘릴 때는 공간을 따로 마련한다.


############################################################
#  A. 설치
############################################################

[1] Windows 쪽 준비
------------------------------------------------------------
- NVIDIA 드라이버를 최신으로 업데이트한다 (평소 쓰는 NVIDIA 앱에서).
  Windows 에는 CUDA 를 따로 깔지 않는다.
- E: 의 파일 시스템이 NTFS 인지 확인한다.
  파일 탐색기 -> E: 오른쪽 클릭 -> 속성 -> "파일 시스템" 이 NTFS 면 된다.
  exFAT 이면 안 된다 (이때는 진행하지 말고 먼저 물어본다).
  포맷할 필요는 없다. E: 의 기존 파일은 건드리지 않고 E:\wsl 폴더만 새로 생긴다.


[2] Ubuntu 설치  -  관리자 PowerShell
------------------------------------------------------------
wsl --install -d Ubuntu-24.04

-> 재부팅. Ubuntu 창이 뜨면 사용자 이름과 암호를 만든다.


[3] Ubuntu 를 E: 로 옮기기  -  관리자 PowerShell
------------------------------------------------------------
wsl --shutdown
mkdir E:\wsl
wsl --export Ubuntu-24.04 E:\wsl\ubuntu.tar
wsl --unregister Ubuntu-24.04
wsl --import Ubuntu-24.04 E:\wsl\ubuntu E:\wsl\ubuntu.tar
del E:\wsl\ubuntu.tar

이제 리눅스 전체가 E:\wsl\ubuntu\ext4.vhdx 파일 하나에 들어 있다.

안에서 파일을 지워도 이 파일은 줄지 않는다(지운 자리는 Ubuntu 가 다시 쓴다).
그래서 zip 은 Ubuntu 밖(E:\aihub-zip)에 받아 바로 지운다.
'wsl --manage ... --set-sparse true' 는 Microsoft 가 데이터 손상 위험으로 막아 두었다.
--allow-unsafe 로 강제로 켜지 않는다.


[4] 로그인 사용자 되돌리기  -  Ubuntu 터미널
------------------------------------------------------------
wsl -d Ubuntu-24.04 로 열었을 때 이미 내 사용자 이름(예: loodad@...)이면 건너뛴다.
root@... 로 나올 때만 아래를 한다.

sudo tee /etc/wsl.conf <<'EOF'
[user]
default=<처음 만든 사용자 이름>
EOF


[5] 메모리 한도  -  메모장
------------------------------------------------------------
C:\Users\<내 이름>\.wslconfig 파일을 만들고 아래 두 줄을 넣는다.
(RAM 16GB 면 12GB, 32GB 면 24GB 정도)

[wsl2]
memory=12GB

-> PowerShell 에서 wsl --shutdown 후 Ubuntu 를 다시 열면 [4], [5] 가 적용된다.


[6] 필요한 프로그램  -  Ubuntu 터미널
------------------------------------------------------------
sudo apt update
sudo apt install -y build-essential git automake autoconf libtool sox gfortran python3 python3-pip zlib1g-dev wget unzip unar subversion libopenblas-dev locales
sudo locale-gen en_US.UTF-8
pip3 install --break-system-packages morfessor

nvidia-smi
-> RTX 5070 이 보이면 GPU 연결 성공


[7] CUDA 12.8  -  Ubuntu 터미널
------------------------------------------------------------
wget https://developer.download.nvidia.com/compute/cuda/repos/wsl-ubuntu/x86_64/cuda-keyring_1.1-1_all.deb
sudo dpkg -i cuda-keyring_1.1-1_all.deb
sudo apt update
sudo apt install -y cuda-toolkit-12-8

/usr/local/cuda/bin/nvcc --version
-> 12.8 이 나오면 성공


[8] Kaldi 빌드 (1~2시간)  -  Ubuntu 터미널
------------------------------------------------------------
git clone -b claude/eloquent-cray-29ssw9 https://github.com/Kolopen/bodeultext.git ~/bodeultext
git clone https://github.com/Kolopen/-AI.git ~/-AI

cd ~/bodeultext/tools
make -j 8

cd ../src
./configure --shared --use-cuda --cudatk-dir=/usr/local/cuda --cuda-arch="-gencode arch=compute_120,code=sm_120"
make depend -j 8
make -j 8

확인:
cd ../egs/yesno/s5
./run.sh
-> 마지막에 %WER 0.00 이 나오면 설치 끝


[9] 데이터 받기 (zip 은 하나씩 풀고 바로 지운다)  -  Ubuntu 터미널
------------------------------------------------------------
zip 은 E: 의 Windows 쪽 폴더에 받고, 푼 것만 Ubuntu 안에 둔다.
(Ubuntu 안에서 E: 는 /mnt/e 로 보인다)

mkdir -p /mnt/e/aihub-zip ~/aihub
cd /mnt/e/aihub-zip
curl -o aihubshell https://api.aihub.or.kr/api/aihubshell.do
chmod +x aihubshell
./aihubshell -mode l | grep 의료진
-> datasetkey 번호 확인

라벨부터 (1.3GB):
./aihubshell -mode d -datasetkey <번호> -filekey 48745 -aihubapikey '<API키>'
-> 받은 zip 이름은 ls 로 확인
unar -o ~/aihub/train/labels <받은 zip>
rm <받은 zip>
(Validation 라벨 48759 는 ~/aihub/valid/labels 로 같은 방법)

음성 (하나씩, 받기 -> 풀기 -> 지우기):
  48750 의료진_의사_1 -> ~/aihub/train/audio
  48753 환자_1        -> ~/aihub/train/audio
  48761 Validation 의료진_의사_1 -> ~/aihub/valid/audio
  48762 Validation 환자_1        -> ~/aihub/valid/audio

df -h ~
-> 중간중간 남은 공간 확인

aihubshell 명령 형식은 AI-Hub 의 aihubshell 가이드 기준으로 확인한다.

라벨 점검, 학습은 같은 폴더의 README.md 5~6절.


############################################################
#  B. 제거
############################################################

[1] 남길 것 먼저 빼기  -  Ubuntu 터미널
------------------------------------------------------------
학습한 모델만 E: 의 Windows 쪽 폴더로 복사한다 (수백 MB).

mkdir -p /mnt/e/kaldi-model
cd ~/bodeultext/egs/aihub_medical/s5
cp -rL exp/chain/tdnn1a_online exp/chain/tree/graph data/lang_test /mnt/e/kaldi-model/


[2] 이름 확인  -  관리자 PowerShell
------------------------------------------------------------
wsl -l -v

-> 목록의 이름이 Ubuntu-24.04 가 아니면 아래 명령에서 그 이름으로 바꾼다.


[3] Ubuntu 삭제  -  관리자 PowerShell
------------------------------------------------------------
!! Kaldi, CUDA, AI-Hub 데이터, 학습 결과가 전부 지워진다. 되돌릴 수 없다. !!

wsl --shutdown
wsl --unregister Ubuntu-24.04
Remove-Item -Recurse -Force E:\wsl
Remove-Item -Recurse -Force E:\aihub-zip
Remove-Item $env:USERPROFILE\.wslconfig


[4] 시작 메뉴의 Ubuntu 앱 제거
------------------------------------------------------------
설정 -> 앱 -> 설치된 앱 -> "Ubuntu 24.04 LTS" -> 제거
(목록에 없으면 건너뛴다)


[5] WSL 기능까지 끄기 (선택: 다시 안 쓸 때만)  -  관리자 PowerShell
------------------------------------------------------------
wsl --uninstall
dism /online /disable-feature /featurename:Microsoft-Windows-Subsystem-Linux /norestart
dism /online /disable-feature /featurename:VirtualMachinePlatform /norestart

-> 재부팅하면 설치 전 상태.

NVIDIA 드라이버는 원래 쓰던 것이라 그대로 둔다.
Windows 쪽에는 CUDA 를 깔지 않았으므로 지울 것이 없다.
